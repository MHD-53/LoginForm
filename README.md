# Dark Login UI

A simple and elegant login interface built with HTML and CSS, featuring a dark theme, purple accents, and floating labels.

✨ Features

- Dark-themed design with purple accents.
- Floating label input fields.
- Clean and minimal user interface.
- Built with pure HTML and CSS.

🛠️ Technologies

- HTML5
- CSS3

🚀 Getting Started

1. Clone or download this repository.
2. Open "index.html" in your web browser.

📚 Purpose

This is a small educational project created to practice HTML and CSS styling techniques, particularly floating label animations and dark-themed UI design.
